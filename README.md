# Лабораторная работа №1

Три консольные программы решают биквадратное уравнение `Ax⁴ + Bx² + C = 0` и выводят только действительные корни:

- `roots_proc.py` — процедурный подход;
- `roots_oop.py` — объектно ориентированный подход;
- `roots_func.py` — функциональный подход с сопоставлением с образцом.

Для запуска нужен Python 3.10 или новее. Например:

```powershell
python roots_proc.py 1 -5 4
python roots_oop.py 1 -5 4
python roots_func.py 1 -5 4
```

Коэффициенты можно передать позиционными аргументами `A B C`. Отсутствующий или некорректный коэффициент программа запрашивает с клавиатуры до корректного ввода. Допускаются конечные действительные числа с десятичной точкой. Если `A = 0`, программа решает уравнение меньшей степени.

Отчёт находится в файле `Отчет_лабораторная_работа_1.docx`.
